Important

Premier lancement — utilisez v1.0.13

Si Windows affiche un avertissement de sécurité, cliquez sur Plus d'infos puis Exécuter quand même. C'est normal pour une application non signée.

  • Fermez LocAgence Pro / Electron dans le Gestionnaire des tâches
  • Désinstallez via Paramètres → Applications
  • Supprimez le dossier %APPDATA%\rental-car-crm si une installation précédente a échoué
  • Téléchargez et installez LocAgencePro-Setup-1.0.13.exe
  • Entrez la clé d'essai 7 jours, puis connectez-vous
